# Desolator (Fabric 26.2)
Нужны: Java 25, Gradle 9.5+ (или сгенерируйте wrapper командой `gradle wrapper`).
Сборка: `gradle build` -> `build/libs/desolator-1.0.0.jar`. Кладите в mods/ вместе с Fabric API.
Текстура-заглушка: src/main/resources/assets/desolator/textures/item/desolator.png - замените на свою.
